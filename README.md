lastseen.dev provides an independent temporal notary service for software components, offering dated, hash‑chained observations of the public record. Users can submit a repository, organization, or package manifest and receive the date when the component was last observed, along with source details and censoring status. The platform records observations in a daily SHA‑256 hash chain, publicly anchored for verifiable integrity. It supports free, unauthenticated queries under a generous rate limit, and offers additional paid capabilities with advance notice. The service emphasizes transparency, open data, and a commitment to preserving the historical state of software dependencies without predictions or scores.
